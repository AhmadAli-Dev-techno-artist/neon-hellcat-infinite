# Neon Hellcat — Infinite City 🏎️✨

An infinite, synthwave-themed 3D driving simulation built with Three.js, WebGL, and Web Audio API.

### 🎮 Live Demo: [Play in Browser](your-pages-link-here)

### ✨ Features
- **Procedural Infinite City:** Dynamic chunk streaming with `InstancedMesh` for high-performance rendering.
- **Dynamic Time & Sky:** Custom GLSL sky shader with procedural clouds, day/night transitions, and synthwave aesthetics.
- **Vehicle Physics:** Gearbox torque ratios, drift slip angle calculation, body roll suspension, and tire skid mechanics.
- **Synthesized Audio:** Engine roar, supercharger whine, screeching, and horns synthesized via raw Web Audio API oscillators (zero external audio files).
- **AI City Traffic & Pedestrians:** Lane switching, intersection signal awareness, and collision detection.

### 🛠️ Built With
- JavaScript / Three.js (r128)
- Custom GLSL Shaders
- Web Audio API
- Rapidly prototyped and iterated using modern AI workflows
